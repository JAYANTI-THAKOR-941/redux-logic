# Redux Counter Logic

React counter exercise for exploring centralized state management.

## Project structure

- `redux-logic/src/components/Counter.jsx`
- `redux-logic/src/store/store.js`

## Getting started

Install Node.js and npm, then run:

```bash
git clone https://github.com/JAYANTI-THAKOR-941/redux-logic.git
cd redux-logic
cd redux-logic
npm install
npm run dev
```

Open the development URL displayed in the terminal.
